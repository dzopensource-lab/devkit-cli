# 🤝 Contributing to DevKit CLI

Thanks for your interest in contributing! Here's how to get started.

---

## 🚀 Quick Setup

```bash
git clone https://github.com/YOUR_USERNAME/devkit-cli.git
cd devkit-cli
python -m venv .venv
pip install -e .
pip install pytest
pytest

🌿 Branch Naming
Type	Pattern	Example
Feature	feature/<name>	feature/clean-command
Bugfix	fix/<name>	fix/organize-crash
Docs	docs/<name>	docs/improve-readme
✅ Before Submitting a PR

    □

    Tests pass: pytest
    □

    Added tests for new features
    □

    Updated README if behavior changed

📝 Commit Message Format

We follow Conventional Commits:
text

<type>: <description>

Types: feat:, fix:, docs:, refactor:, test:, chore:
