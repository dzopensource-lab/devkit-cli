# 🛠️ DevKit CLI

**A modern CLI toolkit for developers — organize files, scaffold projects, inspect git repositories.**

[![PyPI](https://img.shields.io/badge/PyPI-coming%20soon-blue)](https://pypi.org/)

---

## ✨ Features

- 📂 **`devkit organize`** — Sort files in any folder into `Images/`, `Documents/`, `Code/`, etc.
- 🧱 **`devkit scaffold`** — Generate a new project from built-in templates (`web`, `python-cli`)
- 📊 **`devkit git-stats`** — Quick overview of commits, branch, and last author of a repo
- 🎨 **Rich terminal output** — Colors, tables, and clear feedback
- 🧪 **Tested** — Built with testability in mind
